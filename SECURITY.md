# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through GitHub's private vulnerability
reporting feature, not through a public issue:

1. Go to the [Security tab](https://github.com/SnapDogRocks/snapdog/security)
   of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version, and, if possible, steps to
   reproduce it.

This opens a private advisory visible only to the maintainers and to you,
so the report does not disclose the issue publicly before a fix is available.

## Response Time

We aim to acknowledge a report within 5 business days. How long a fix takes
depends on the severity and complexity of the issue; we will keep you updated
on progress and coordinate a disclosure timeline with you.

## Supported Versions

SnapDog does not yet maintain multiple release branches. Security fixes are
released against the latest published version on the `main` branch.
